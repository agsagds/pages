Harness: что это?

Agent harness — весь код, конфигурация и логика исполнения вокруг language model.

Model даёт интеллект. Harness даёт state, tools, memory, orchestration и ограничения.

Agent = Model + Harness
Harness Layer
MODEL
Prompts · Tools · Memory · Loop
Guardrails · Observability · Storage

Чего harness НЕ делает

×

×

Базовый цикл: Reason → Act → Observe

Model читает контекст и выбирает следующее действие
Harness запускает tool и фиксирует результат
Результат возвращается как новый контекст

Self-Harness: агенты, которые улучшают себя

Self-harness позволяет агенту улучшать собственный scaffolding без участия человека.

1. Mine
Слабые места в tools / memory
2. Propose
Изменения собственных инструкций
3. Validate
Проверка на benchmark

Прирост на бенчмарках без смены model — за счёт лучшего harness.

Manual vs Self-Harness

Люди — узкое место при каждом новом model; Self-Harness крутит цикл по traces.

Runtime vs Framework vs Harness

СлойЧто даётOpinionПримеры
RuntimeExecution state и durable flowsНетLangGraph, Temporal
FrameworkАбстракции агентов и toolsНизкаяLangChain, CrewAI, OpenAI SDK
HarnessOpinionated config и bundled infraВысокаяClaude Code, Codex, Cursor

Node — runtime, Express — framework, Next.js — harness.

Opinion / opinionated — насколько слой заранее решает за вас (loop, memory, tools, safety, defaults). Runtime — почти без opinion; Framework — низкая (абстракции, вы собираете); Harness — высокая (готовая система «из коробки»).

Частые вопросы

Что такое AI harness? +
AI harness — ПО, конфигурация и логика исполнения вокруг large language model: prompts, tools, memory, orchestration, evaluation и guardrails. Коротко: Agent = Model + Harness.
Чем AI agent отличается от AI harness? +
AI agent — целая система. AI harness — часть без model: scaffolding, tools и проверка output. Агент = model + harness.
Framework вроде LangChain — это harness? +
Нет. Framework — toolkit, чтобы быстрее собрать harness. Harness — конкретная конфигурация под ваш use case.
Нужен ли harness, чтобы собрать AI agent? +
Да. Любой agent с tools, контекстом, state или validation уже работает через harness — вопрос в осознанном дизайне.
Какие ядровые компоненты у AI harness? +
Контекст, tools, memory, orchestration, evaluation, tracing/observability, guardrails — обычно наращивают постепенно.
С чего начать сборку AI harness? +
Версионированные промпты, retrieval pipeline, registry tools, validation output, логирование; затем evaluation и tracing.
